# Datos de QF Nexus

Este repositorio lo actualiza sola la aplicación **Tablero SUGEF**. Contiene la
foto de datos que descarga la app de iPhone de QF Nexus:

- `datos.json`: indicadores calculados con información pública de SUGEF.
- `datos.json.sig`: la firma de ese archivo.

No edite estos archivos a mano: la app de iPhone rechaza cualquier archivo que
no esté firmado por la computadora que publica.
